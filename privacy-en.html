Privacy Policy

Last Updated: July 8, 2026

This Privacy Policy explains what information our application collects, how it is used, how it is stored, and the rights users have regarding their personal data.

By using this application, you agree to this Privacy Policy.

1. Information We Collect

To provide the application's core features and services, we may collect the following information:

  • Email address
  • Username (nickname)
  • Profile photo
  • User-created posts
  • Private messages exchanged between users
  • Firebase Cloud Messaging (FCM) token
  • Profile information created within the application
  • Other content voluntarily shared by users

This information is collected solely to provide the application's functionality.

2. How We Use Your Information

Your information may be used to:

  • Create and manage user accounts
  • Authenticate users securely
  • Display user profiles
  • Enable post sharing
  • Enable private messaging
  • Send push notifications
  • Maintain application security
  • Detect and resolve technical issues
  • Improve application performance
  • Provide all core application features

Personal information is not sold to third parties for advertising purposes.

3. Data Storage

User data is securely stored using Google Firebase services.

Services used include:

  • Firebase Authentication
  • Cloud Firestore
  • Firebase Cloud Messaging (FCM)

Appropriate security measures provided by Firebase are used to protect user data. However, no method of data transmission over the Internet can be guaranteed to be completely secure.

4. Push Notifications

The application uses Firebase Cloud Messaging (FCM) to deliver push notifications.

Your device's FCM token may be stored solely for notification delivery.

5. Third-Party Services

The application may use the following third-party services:

  • Firebase Authentication
  • Cloud Firestore
  • Firebase Cloud Messaging (FCM)
  • Google Play Services

These services operate under their own privacy policies.

6. Account Deletion

Users may delete their accounts from within the application.

When an account is deleted:

  • The user account is removed.
  • Authentication credentials are deleted.
  • Profile information is removed.
  • Previously sent messages remain available.
  • Previously published posts remain available.

Messages and posts may remain in the system to preserve conversations and the experience of other users.

7. Data Security

Reasonable technical and organizational measures are implemented to protect user information against unauthorized access, alteration, disclosure, or destruction.

8. Children's Privacy

The application is not intended to knowingly collect personal information from children in violation of applicable laws.

9. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time.

Any changes become effective immediately upon publication on this page. Users are encouraged to review this policy periodically.
